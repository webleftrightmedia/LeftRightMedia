# Left Right Media

Hyper-local digital billboard platform for Tier-2 & Tier-3 India. Monetize commercial screens with a smart 55/45 content split architecture.

## Structure

```
/client   — React + Vite frontend (landing page, lead capture)
/server   — Node + Express API (leads, screens) — coming soon
/docs     — Design tokens, architecture docs
```

## Getting Started

### Client
```bash
cd client
npm install
npm run dev
```

### Server
Coming in a future phase. See `/server/README.md`.

## Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS
- **Backend**: Node.js, Express, MongoDB (planned)
- **Fonts**: Space Grotesk, Inter, JetBrains Mono
